# WH Yandex Reviews Exporter

Локальный экспортёр отзывов организации WH из публичной карточки
Яндекс Карт.

Экспортёр предназначен только для организации:

- Название: WH
- Business ID: 33357510992
- Источник:
  https://yandex.ru/maps/org/wh/33357510992/reviews/

## Принцип работы

1. Скрипт запускается вручную на компьютере администратора.
2. Playwright открывает публичную карточку организации.
3. Скрипт создаёт локальный JSON-файл.
4. JSON вручную импортируется в плагин WH Reviews.
5. На сервере WordPress Playwright и Python не требуются.
